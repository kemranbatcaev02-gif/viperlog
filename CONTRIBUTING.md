# Участие в разработке ViperLog

Будем рады вашим предложениям по оптимизации SIMD-парсинга и новым правилам маскирования логов!

## Разработка:
- Установленный стабильный Rust Toolchain (`rustup update stable`).
- Проверка форматирования: `cargo fmt --check`.
- Проверка линтером: `cargo clippy --all-targets -- -D warnings`.
- Запуск тестов: `cargo test`.
- Запуск бенчмарков: `cargo bench`.

## Оформление изменений:
1. Создайте ветку `feature/название`.
2. Убедитесь, что `cargo test` проходит без ошибок.
3. Откройте Pull Request с описанием улучшений производительности или новой функциональности.
